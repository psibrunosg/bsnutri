# Imagens do painel

Fotos decorativas da Visão geral, servidas pelo Vite e versionadas no GitHub. São
**genéricas, para substituição** pelas fotos definitivas da clínica — troque o arquivo
mantendo o mesmo nome e o painel muda sozinho, sem alterar código.

| Arquivo | Uso | Origem |
|---|---|---|
| `hero-bowl.webp` | Faixa do topo da Visão geral | [Salad Bowl](https://commons.wikimedia.org/wiki/File:Salad_Bowl_(Unsplash).jpg) |
| `plan-1.webp` | Miniatura de plano recente | [Healthy Lentil Salad](https://commons.wikimedia.org/wiki/File:Healthy_Lentil_Salad_(Unsplash).jpg) |
| `plan-2.webp` | Miniatura de plano recente | [Fresh Salad](https://commons.wikimedia.org/wiki/File:Fresh_Salad_(Unsplash).jpg) |
| `plan-3.webp` | Miniatura de plano recente | [Bowl of Fresh Fruit](https://commons.wikimedia.org/wiki/File:Bowl_of_Fresh_Fruit_(Unsplash).jpg) |
| `plan-4.webp` | Miniatura de plano recente | [Healthy Meal Prep](https://commons.wikimedia.org/wiki/File:Healthy_Meal_Prep_(Unsplash).jpg) |

Todas vêm do Wikimedia Commons, publicadas originalmente no Unsplash sob **CC0**
(domínio público, sem exigência de atribuição). Foram recortadas e convertidas para
WebP no tamanho exato de exibição.

As miniaturas de plano são escolhidas por posição na lista (`plan-1` … `plan-4`), não
por identificador de plano — quatro arquivos cobrem o painel inteiro.
